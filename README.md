Loyola Academic Performance Analysis Dashboard

Project Overview:
This project analyzes student academic performance, attendance, examination results, credits earned, and assessment outcomes using Microsoft Excel and Power BI.

The objective is to provide actionable academic insights through interactive dashboards that help monitor student performance, attendance trends, examination outcomes, and departmental achievements.

Tools Used:
1.Microsoft Excel
2.Power BI

Dataset Description:
The project uses the following datasets:

Students:
Contains student demographic and academic information.

Columns include:
1.Roll Number
2.Student Name
3.Gender
4.Date of Birth
5.Year of Join
6.Program
7.Degree Type
8.Department
9.District
10.City

Subjects:
Contains subject information and credit details.

Columns include:
1.Subject Code
2.Subject Name
3.Program
4.Degree Type
5.Semester
6.Credit Points
7.Maximum Marks

Scores:
Stores student marks and examination performance.

Columns include:
1.Roll Number
2.Program
3.Degree Type
4.Semester
5.Subject Code
6.Subject Name
7.Exam Type
8.Raw Marks

Attendance Monthly:
Monthly attendance records.

Columns include:
1.Roll Number
2.Subject Code
3.Month
4.Total Classes
5.Attended Classes
6.Attendance Percentage
7.Shortage Reason

Attendance Summary:
Overall attendance information for each student and subject.

Credits Semester:
Semester-wise credit information.

Columns include:
1.Roll Number
2.Semester
3.Total Credits
4.Credits Earned

Exams:
Examination details.

Columns include:
1.Exam ID
2.Exam Type
3.Semester
4.Exam Date
5.Exam Hall
6.Invigilator

Viva Split
Student viva assessment scores.

Columns include:
1.Report Score
2.Presentation Score
3.QA Score
4.Total Viva Score

Project Panel:
Project guide and viva panel allocation details.
